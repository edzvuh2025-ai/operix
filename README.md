# Operix — Roblox Group Management Platform

Full-stack SaaS platform for managing Roblox groups with staff, moderation analytics.

## Quick Start
```bash
pnpm install
cp .env.example .env
pnpm db:migrate && pnpm db:seed
pnpm dev
```

## Tech
React + Vite + Node.js + Express + PostgreSQL + Clerk

## Deploy
Railway-compatible. See railway.json files in artifacts/
